# Stand-in models

Every glb is CC0 1.0 from Kenney (https://kenney.nl), copied unchanged; `Textures/colormap.png` is the Survival Kit's shared palette. `tools/bsp/dotbsp/free_models.tsv` says which source model path each stands for; a source model is never shipped.

- [Furniture Kit](https://kenney.nl/assets/furniture-kit): sofa, armchair, chair, office_chair, stool, bench, table, desk, bookcase, bed, tv, monitor, ceiling_light, lamp, floor_lamp, plant, plant_small, bin, toilet, sink, fridge, stove, radio, speaker, washer, bathtub, coat_rack, cardboard_box, rug, side_table, cabinet, kitchen_cabinet
- [Survival Kit](https://kenney.nl/assets/survival-kit): crate, crate_large, barrel, chest, bucket, signpost, fence_post
- [Nature Kit](https://kenney.nl/assets/nature-kit): tree, tree_pine, fence, rock, log, stump, bush
- [Car Kit](https://kenney.nl/assets/car-kit) (ids `vehicles/<name>`, with their own `Textures/colormap.png`): truck, sedan, van (the kit's delivery), garbage-truck
- [Factory Kit](https://kenney.nl/assets/factory-kit) (`factory/`: door, pipe, window), [Graveyard Kit](https://kenney.nl/assets/graveyard-kit) (`graveyard/`: gravestone, cross, lamppost), [Pirate Kit](https://kenney.nl/assets/pirate-kit) (`pirate/`: boat, palm, bottle), [Prototype Kit](https://kenney.nl/assets/prototype-kit) (`prototype/`: ladder) and the Car Kit's `vehicles/cone`: each folder carries that kit's own `Textures/colormap.png`.
- 2026-10-24: [Food Kit](https://kenney.nl/assets/food-kit) (`food/`: bottle-ketchup, bottle-musterd, bottle-oil, burger), [Watercraft Pack](https://kenney.nl/assets/watercraft-pack) (`watercraft/cargo-container-a`), [Mini Arcade](https://kenney.nl/assets/mini-arcade) (`arcade/`: arcade-machine, vending-machine) and [Space Kit](https://kenney.nl/assets/space-kit) (`space/`: machine_generator, machine_generatorLarge, machine_barrelLarge, craft_cargoA). All CC0 1.0 by Kenney, copied unchanged; each folder with a `Textures/colormap.png` carries its kit's own, the Space Kit glbs embed theirs.
